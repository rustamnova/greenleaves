# Синтетический пример Greenleaves v0.3

Дата расчёта: 29.09.2026. Это искусственный демонстрационный участок, а не исходные инженерные данные и не результат проверки 20 улиц.

- `input.dxf` — тот же синтетический вход, что `examples/demo-input.dxf` в репозитории.
- `planting-plan.dxf` — исходные сущности плюс предложения на слоях GREENLEAVES_*.
- `report.json` — параметры, допущения, геометрические объяснения, отклонения и SHA-256 входа. Конкретные проверенные пункты НПА пока отсутствуют.

Параметры: balanced, шаг 4 м, лимит 180. Результат: 56 деревьев + 124 кустарника, 274 отклонённых кандидата. `capped: true` означает частичный расчёт из-за лимита.

Независимая проверка ezdxf 1.4.4: 366 сущностей, 0 ошибок, 0 автоматических исправлений. Она не заменяет проверку в CAD на целевой ОС и нормативную экспертизу.

Воспроизведение из публичного репозитория:

```bash
node scripts/cli.mjs --demo --output output/demo
```

Дата генерации JSON меняется между запусками. Геометрия при тех же параметрах детерминирована. Численные отступы являются инженерными допущениями; эти файлы не следует использовать как утверждённый план посадки.
