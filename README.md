# Greenleaves

Генеративное проектирование городского озеленения. Прототип для задачи №3 **ЛЦТ 2026 / ДПиООС Москвы**.

[Сайт](https://rustamnova.github.io/greenleaves/) · [DXF-студия](https://rustamnova.github.io/greenleaves/studio/?demo=1) · [Методика](https://rustamnova.github.io/greenleaves/docs.html) · [План до сдачи](docs/ROADMAP.md)

**Статус:** инженерный прототип v0.2. Нормативная матрица и проверка на полном реальном датасете не завершены. Версия не готова к финальной сдаче и не выдаёт утверждённые проекты посадки.

## Возможности

- Один текстовый DXF → классификация слоёв → варианты посадки → DXF + JSON/CSV.
- Проверка замкнутой границы, площадных препятствий, коммуникаций, неизвестных объектов, взаимного расстояния деревьев и кустарников.
- Три сценария; ручные добавление, перенос, удаление; текстовые команды и отмена.
- Повторная геометрическая проверка каждой ручной правки и экспорта.
- Чертёж обрабатывается локально в браузере. Внешний AI API, регистрация и платный сервер не нужны.
- Исходные объекты сохраняются; новые сущности добавляются на слои `GREENLEAVES_TREES`, `GREENLEAVES_SHRUBS`, `GREENLEAVES_LABELS`.

Алгоритм детерминированный, без обученной нейросети/LLM. ТЗ допускает алгоритмический подход. Численные расстояния — проектные допущения. Дубай обозначен только как направление исследования.

## Локальный запуск

Требуется Node.js 20+; установка npm-пакетов не нужна.

```bash
git clone https://github.com/rustamnova/greenleaves.git
cd greenleaves
node scripts/serve.mjs
```

Открыть `http://127.0.0.1:4173/`. Нажать «Попробовать на участке» или загрузить DXF. Проект хранится в памяти страницы: экспортируйте результат перед закрытием.

## CLI без браузера

```bash
node scripts/cli.mjs --demo --output output/demo
node scripts/cli.mjs --input /data/site.dxf --output output/site --config config.json
```

Необязательный `config.json`:

```json
{"scale":1,"boundaryLayer":"ГРАНИЦА_ПРОЕКТА","roles":{"ВОДОПРОВОД":"utility"},"step":4,"max":180,"variant":"balanced"}
```

`scale` — единицы DXF на метр: 1 для м, 100 для см, 1000 для мм. Без него используются `$INSUNITS` (4/5/6); неизвестные единицы блокируют расчёт. Выход: `planting-plan.dxf`, `report.json` с SHA-256 исходного файла. CSV доступен в студии.

## Docker / Linux / МосТех.ОС

```bash
docker build -t greenleaves:0.2 .
docker run --rm -p 127.0.0.1:8080:8080 greenleaves:0.2
# открыть http://127.0.0.1:8080
docker run --rm -v "$PWD/output:/output" greenleaves:0.2 node scripts/cli.mjs --demo --output /output
```

Образ запускается от пользователя `node`. Папка `/output` должна быть доступна ему на запись. Dockerfile включает тесты. **Сборка Docker и работа на МосТех.ОС ещё не проверены:** Docker в текущей среде отсутствует. Нужны проверка на Linux и открытие DXF в CAD. HTTP API нет: сервер отдаёт только статические файлы, OpenAPI к нему не применяется.

## Обязательно до сдачи

1. Проверить таблицу отступов и конкретные пункты НПА; выдавать их по каждой принятой и отклонённой посадке.
2. Подготовить полноценную геоподоснову реального пилотного участка; поддержать нужные CAD-объекты и доказать сохранность исходных слоёв.
3. Проверить Docker / Linux / МосТех.ОС и выходной DXF в CAD.
4. Подготовить презентацию 10–20 слайдов, сохранив шаблонные слайды 7–11; документацию с экспортом PDF; демо 4–10 минут.
5. Проверить публичный доступ к ссылкам и сохранить их в кабинете до стоп-кода.
