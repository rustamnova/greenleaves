# Подготовка сложного CAD для Greenleaves v0.3

Новый локальный этап разворачивает подготовленный DXF в отдельную плоскую аналитическую копию. Он не заменяет проверку полноты DWG-конвертации и работу проектировщика. Исходные файлы не перезаписываются. Реальные CAD и конфигурации с путями храните в `.private/`.

## Запуск

Нужен Python 3.11+ с зависимостями из `requirements-cad.txt` в отдельном окружении:

```sh
python -m pip install -r requirements-cad.txt
python scripts/prepare-cad.py --config .private/pilot.json --output .private/prepared
node scripts/cli.mjs --input .private/prepared/analysis-input.dxf --config .private/prepared/config.json --output .private/result
```

Последнюю команду выполняют только после успешной подготовки и проверки назначения слоёв. `analysis-input.dxf` можно открыть в браузерной студии. Роли слоёв и запас на подготовку автоматически читаются из файла. Метры (`$INSUNITS=6`) обязательны на этапе подготовки.

Пример конфигурации, все имена условные:

```json
{
  "boundary": {"file": ".private/base.dxf", "handle": "ABCD"},
  "sources": [".private/trees.dxf"],
  "xrefs": {"BASE": ".private/base.dxf"},
  "layer_rules": [
    {"pattern": "^PROJECT_BOUNDARY$", "role": "boundary"},
    {"pattern": "WATER|GAS|CABLE", "role": "utility"},
    {"pattern": "BUILDING", "role": "building"},
    {"pattern": "TREE", "role": "existing"},
    {"pattern": "TITLE_BLOCK", "role": "ignored", "reason": "Проверенная рамка и штамп за пределами проекта"}
  ],
  "tolerance_m": 0.03,
  "step": 4,
  "max": 1000
}
```

`boundary.handle` задаёт существующий замкнутый контур, а не искусственный прямоугольник. Необязательный `pilot_window: [xmin,ymin,xmax,ymax]` пересекает его с явно выбранным фрагментом. Внешние ссылки разрешаются только явным словарём `xrefs`. Названия слоёв не доказывают их смысл: правила должен подтвердить специалист. Неизвестные слои становятся препятствиями. Исключение слоя требует записанной причины.

## Геометрия и ограничения

- Разворачиваются вложенные INSERT/MINSERT: базовая точка, перенос, поворот, неравномерный масштаб и наследование слоя 0. Вложенность ограничена 32 уровнями.
- Поддерживаются линии, точки, полилинии, дуги, окружности, сплайны, эллипсы, HATCH/MPOLYGON, SOLID/TRACE/3DFACE. Кривые приближаются отрезками. Координата Z проецируется на план XY; анализ высот отсутствует.
- REGION поддерживается только при полном читаемом ACIS: плоские поверхности и прямолинейные границы. Нечитаемый REGION, отсутствующая ссылка или иной существенный неподдерживаемый объект блокируют подготовку. Пустой объект не исключается только потому, что остальные известные объекты лежат далеко.
- Отверстия штриховок заполняются как исключения. Самопересекающееся замкнутое препятствие заменяется выпуклой оболочкой с записью в аудите. Это может убрать допустимые места и завысить запретную область.
- `tolerance_m` управляет приближением и добавляет консервативный запас к расстояниям в общем JS-ядре. Это инженерная настройка, а не сертифицированная оценка ошибки DWG-конвертера. Нельзя компенсировать ею потерянные объекты или неверный смысл слоя.
- Рассматриваются объекты в пределах контура плюс 10 м; текущие буферы не превышают 5 м. При изменении правил этот предел нужно пересмотреть. Открытые линии дорог и зданий не превращаются автоматически в площадные запреты: нужен отдельный контроль полноты контуров и маски пригодной территории.

## Выход и происхождение

Всегда сохраняются `preparation-audit.json` (статус, хеши источников, счётчики, ошибки) и `diagnostic-geometry.json` (распознанные фрагменты для локальной диагностики). При ошибках **DXF для расчёта не создаётся**. Наличие диагностической геометрии не означает разрешение на посадку.

При успехе добавляются `analysis-input.dxf`, `config.json`, `geometry-provenance.json`. Каждому фрагменту сопоставляются источник, handle, исходный слой и цепочка блоков. Производная геометрия размещается только на слоях `GREENLEAVES_*`. Повторная запись поверх существующего аналитического DXF запрещена.

Экспорт студии сохраняет сущности **загруженного DXF**. Для аналитической копии это её сущности; обещания побайтового сохранения первоначального DWG нет. Перенос результатов обратно на оригинальную подоснову и открытие в целевой CAD-системе требуют отдельной проверки.

Регрессии: `python -m unittest discover -s tests -p test_prepare_cad.py` и `node --test tests/*.test.mjs`.
