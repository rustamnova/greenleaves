# Сценарий живой демонстрации Greenleaves

Продолжительность: около 6 минут. Синтетический пример; инженерные расстояния пока не подтверждены нормативной экспертизой. Этот сценарий покрывает доступные функции, но не закрывает пробел с конкретными пунктами НПА и реальным пилотом.

| Время | Действие и пояснение |
|---|---|
| 0:00–0:40 | Назвать задачу: предварительная расстановка деревьев и кустарников с учётом геометрических ограничений. Сразу обозначить статус прототипа и синтетические данные. |
| 0:40–1:20 | Открыть студию, показать границу, препятствия и коммуникации. При необходимости загрузить публичный `materials/demo/input.dxf`. Проверить единицы и роли слоёв. |
| 1:20–2:10 | Рассчитать вариант при шаге 4 м и лимите 180. Показать 56 деревьев / 124 кустарника и предупреждение о лимите. Это не полный перебор всех возможных посадок. |
| 2:10–3:10 | Показать пояснение к точке и причину отказа в запретной области. Честно сообщить, что ссылки на конкретные пункты НПА пока отсутствуют. Показать ручную правку и отмену. |
| 3:10–4:10 | Скачать DXF и JSON. Показать слои GREENLEAVES_TREES, GREENLEAVES_SHRUBS, GREENLEAVES_LABELS и сохранённые исходные сущности. JSON фиксирует допущения, единицы, роли слоёв и ограничения. |
| 4:10–5:10 | Повторить расчёт через CLI по команде ниже. Показать независимую проверку ezdxf: 366 сущностей, 180 предложений, 0 ошибок и исправлений. Открытие в CAD под целевой ОС выполнить отдельно; не выдавать проверку парсером за проверку в CAD. |
| 5:10–6:00 | Показать архитектуру и реальный пилот: 22 307 распознанных фрагментов, остановка из-за неполной ACIS-геометрии. Завершить конкретными доработками: полноценный CAD-вход, нормативная матрица, Docker/Linux/CAD-проверка. |

```bash
git clone https://github.com/rustamnova/greenleaves.git
cd greenleaves
node scripts/cli.mjs --input examples/demo-input.dxf --output output/demo
node --test tests/*.test.mjs
```

Опциональная независимая проверка требует отдельного Python-окружения с ezdxf:

```bash
python -m pip install -r requirements-cad.txt
python scripts/verify-dxf.py output/demo/planting-plan.dxf output/demo/report.json
```

Если нет доступа к интернету, заранее сохранить исходники и файлы демонстрации. Студию можно запустить локально командой `node scripts/serve.mjs` и открыть `http://127.0.0.1:4173/studio/?demo=1`.
