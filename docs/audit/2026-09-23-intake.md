## Проверенные ограничения

### Архив Python v1

- `read_sources()` принимает контур по имени слоя и числу точек, без требования замкнутости и проверки самопересечений.
- Без границы `generate_placements()` размещает точки по общим габаритам и всё равно пишет DXF. Только confidence понижается до low.
- Расстояния считаются до дискретных точек линий. Площадь внутри здания не исключается, замыкающее ребро замкнутой полилинии без повторённой вершины теряется.
- **В сохранённом синтетическом результате 8 посадок внутри здания** с прямоугольником x=55..75, y=30..45: P00086, P00087, P00088, P00089, P00096, P00097, P00098, P00102. Это проверка переданного результата, а не заявление о повторном полном прогоне старой среды.
- Неизвестные слои перечисляются, но фактически не участвуют в ограничениях. Параметр `unknown_layers_excluded` не применяется.
- Неизвестные единицы молча трактуются как метры; при нескольких файлах используется масштаб первого.
- Посадочные расстояния проверяются только внутри одного типа; дерево и кустарник могут оказаться слишком близко.
- Сводная категория инженерных сетей имеет 2 м для дерева и `null` для кустарника; точные нормы не подтверждены.
- Экспорт сохраняет первый DXF; объекты остальных входных файлов в выход не переносятся.

### Опубликованный браузерный прототип

Исходный JS изучен отдельно от v1. Уже есть несколько улучшений (диагностический режим, запрет проектного DXF без контура, исключение неизвестных слоёв). Остаются риски: расстояние до границы площадных объектов вместо исключения их площади, неполная обработка блоков/кривых, автоматическое принятие неизвестных единиц за метры, межтиповые расстояния и склеивание ENTITIES нескольких DXF без полноценного переноса CAD-ресурсов. Численная нормативная корректность не доказана.

Новый UI не означает, что все эти проблемы из старого Python сохранились в том же виде; версии оценены раздельно.

## Что проверено на реальном файле

В `117861691400001.dxf` новый parser обнаружил 236 поддерживаемых геометрических объектов, units=6; также MPOLYGON 14, HATCH 501, INSERT 1008, LEADER 357. После исключения явно аннотационных слоёв остаются неподдерживаемые объекты, поэтому генерация останавливается. Это правильная диагностика ограниченной версии, но **не успешная обработка реального участка**. В старом RUN_REPORT граница этого файла также указана как отсутствующая.

## Принятые изменения

- Оригинальный Python-код сохранён для аудита в `legacy/python-v1`, без реальных CAD и приватных результатов.
- Новый единый JS-модуль используется в браузере и CLI.
- Реализованы проверки единиц, простого замкнутого контура, площадных препятствий, неизвестных слоёв, смешанного расстояния посадок и ручных правок.
- Экспорт добавляет отдельные слои, не склеивает несколько CAD без разрешения зависимостей.
- Маркетинговые и интерфейсные тексты не выдают проектные допущения за нормативное соответствие.
- [План до сдачи](../ROADMAP.md) выделяет обязательные пробелы.
