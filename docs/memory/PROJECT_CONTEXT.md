# Project context

Greenleaves, ЛЦТ 2026, задача №3 ДПиООС: DXF → ограничения → посадки → DXF и объяснения. В перспективе — исследование адаптации к Дубаю. Пользователь поручил изучить материалы партнёра, вести проект в GitHub и создать бесплатный сайт.

Основной репозиторий: https://github.com/rustamnova/greenleaves. Разработка: Node.js без npm-зависимостей, статический сайт и единое ядро `site/studio/engine.js`, CLI `scripts/cli.mjs`. Dockerfile для Linux. Публикация: `site/` → ветка `gh-pages` → GitHub Pages. Никаких ключей API или загрузки CAD на сервер.

Партнёрский исходный Python v1 сохранён в `legacy/python-v1` как аудитный материал. Он не используется в новом приложении. Датасеты и частные входные материалы остаются локальными в `.private/`/игнорируемых ZIP.

Стоп-код 2026-09-29 23:59 МСК. После него сданные ветки, сайт и документы менять нельзя. ТЗ допускает чистый алгоритм; LLM необязательна. Главные пробелы сейчас: нормативная матрица с точными пунктами, полноценный реальный участок, Linux/CAD-проверка, презентация/PDF и демо.
