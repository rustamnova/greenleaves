# Decisions

## 2026-09-23

- Сохранить исходную v1 для аудита, не выдавать её сохранённые результаты за доказательство готовности.
- Единое независимое JS-ядро для браузера/CLI; чистый алгоритм допустим ТЗ. Без внешней LLM/API до появления нужного сценария.
- Неизвестный масштаб, неоднозначная граница и неподдерживаемая существенная CAD-геометрия блокируют расчёт. Упрощённый bounding box не подменяет проектный контур.
- Один согласованный DXF вместо некорректного склеивания нескольких ENTITIES без CAD-ресурсов.
- Нормативные значения называются допущениями до проверки; Москва и Дубай не используют автоматически общие правила.
- Бесплатная публикация на GitHub Pages, выделенная ветка gh-pages, ручной release с проверкой стоп-кода. Не привязывать каждое изменение main к обновлению стенда.
