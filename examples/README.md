# Синтетический контрольный участок

`demo-input.dxf` — созданный для проекта пример, не реальная улица. Содержит границу, здание, дорогу, водоём, водопровод и существующее дерево. Единицы — метры.

```bash
node scripts/cli.mjs --input examples/demo-input.dxf --output output/example
```

При стандартных настройках: 180 посадок (56 деревьев, 124 кустарника), 274 отклонённых кандидата. Достигнут установленный лимит; весь участок не исчерпан. Экспорт `planting-plan.dxf` и `report.json` появляется в выбранной выходной папке.

Пример позволяет проверить запуск и геометрические ограничения, но не подтверждает нормативное соответствие или обработку реальных исходных данных.
