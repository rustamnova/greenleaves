# Green AI MVP

Локальный воспроизводимый прототип по задаче ДПиООС: один или несколько входных DXF анализируются без передачи данных во внешние сервисы, после чего создаются предложения посадок на отдельных слоях и машиночитаемые объяснения.

## Что уже реализовано

- чтение нескольких DXF;
- классификация слоёв по настраиваемым русским и английским шаблонам;
- расчёт минимальных расстояний до коммуникаций, дорог, зданий, существующих деревьев и воды;
- генерация деревьев и кустарников с контролем взаимного расстояния;
- базовый подбор растений по типу среды;
- сохранение исходного чертежа и добавление только новых слоёв `GREEN_AI_*`;
- JSON и CSV с координатами, ближайшими ограничениями, причинами выбора и нормативным основанием;
- Dockerfile для локального запуска в Linux / МосТех.ОС.

## Запуск

```bash
python -m pip install -e .
green-ai input/general_plan.dxf input/geobase.dxf --config config/default.yml --output-dir output
```

Docker:

```bash
docker build -t green-ai-mvp .
docker run --rm -v "$PWD/data:/data:ro" -v "$PWD/output:/output" green-ai-mvp \
  /data/input.dxf --config /app/config/default.yml --output-dir /output
```

## Выходные файлы

- `planting_proposal.dxf` — исходный первый DXF с новыми слоями результата;
- `planting_explanations.json` — полный объяснимый результат;
- `planting_explanations.csv` — таблица для эксперта и импорта;

## Ограничения текущего MVP

- DWG требуется предварительно преобразовать в DXF, как указано заказчиком на Q&A-сессии.
- Автоклассификация зависит от названий слоёв; неизвестные слои перечисляются в отчёте.
- Точные номера пунктов нормативных документов намеренно помечены для верификации: их нельзя подменять неподтверждёнными ссылками.
- Для промышленной версии потребуются поддержка сложных блоков/XREF, геометрические полигоны вместо дискретной выборки и экспертная таблица ассортимента mos.ru.

Подробности двух проверочных прогонов приведены в `RUN_REPORT.md`.
